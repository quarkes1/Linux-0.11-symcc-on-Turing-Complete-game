# M2 编译器完整化（C89）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 symcc 扩展为完整 C89 编译器（预处理器 + 类型系统 + 运算符/语句 + ABI 扩展 + 可重定位对象 + symld 链接器 + gcc 式驱动 CLI），验收 = **Linux 0.11 内核 51 个 .c 全部编译 + 链接成功**（运行归 M3）。

**Architecture:** 保持"tokenize → parse → codegen"单遍结构。codegen 输出从"绝对地址 asm"改为**可重定位 .sym 对象**（文本格式：段行 + 符号表行，引用形态编码在 asm 语法里）。新链接器 symld 做布局/符号解析/重定位，输出游戏可直接粘贴的绝对 asm（可选手工粘贴流程不变）。CLI 按 gcc 式驱动组织（-E/-S/-c/-o/-I/-D/-save-temps）。

**Tech Stack:** 工具自身 C89 编写，mingw gcc 构建（`PATH="/d/Downloads/msys64/mingw64/bin:$PATH"` 前缀 + mingw32-make）。对象格式 = 文本（教学可见、diff 友好），无二进制序列化。

## Global Constraints

- **全链路大端**：指令 + 数据。位域从存储单元（4 字节）最高位开始分配（spec §11）。
- **硬件**：RAM/DiskA 各 8MB（8388608 字节，emu.c `DISK_SIZE`、emu_main.c 默认 ram_size 已对齐）。帧缓冲 mem[0x2000]，ASCII 8 模式 96×40，行步长 96。栈顶 crt0 设 sp=0x4000（M2 保持，M3 调整）。
- **ABI（M1 不变）**：全栈传参（实参右→左 push，调用方清理）；r1 结果/返回值；r9 地址暂存；r10 帧指针（入口 sp）；参数槽 [r10+8+4k] 复制到栈槽 [r10-4*(k+1)]；epilogue `mov sp,r10; pop r10; ret`；退出码 = halt 时 r1。
- **伪指令多词编码（游戏 .isa 与 emu/asm.c 一致）**：push=8B、pop=8B、call=20B、ret=12B。任何计算指令字节数的地方（codegen 行布局、链接器布局）必须按此展开。
- **游戏汇编器限制**：`mov`/`load_*`/`store_*` 立即数只接受**数字**；`jmp`/条件跳转/`call` 接受 label（含前向引用）。→ 链接器输出：数据引用一律数字，控制流保留函数名 label。
- **寻址硬约束**：跳转目标（J16）必须 ≤0xFFFF（64KB 上限，本架构不可改）。**数据引用默认 16 位（D16）**，链接时校验 ≤0xFFFF，超限报错提示重编译 `--d32`；`--d32` 时 codegen 对数据引用发射 32 位装载序列（`@hi:name`/`@lo:name` 双重定位）。
- **对象格式偏差（相对 spec 6.1）**：spec 定义二进制 .sym；本计划改为**文本对象**（可重定位 asm + `.sym`/`.bss` 表行）。理由：教学可见、无需序列化代码、链接器调试（文本 diff）便宜。重定位信息**不单独列表**，编码在 asm 语法中：`@name`（D16 数据）、`@hi:name`/`@lo:name`（D32 数据）、`call name`/`jmp name`（J16 控制流）。
- **动态调用（函数指针）**：游戏 .isa 无 `call reg`；展开为 `counter r2; add r2,r2,20; push r2; jmp r1`（counter 返回自身指令地址，+20 = 展开序列 5 字结束处；ret 弹出即达序列后）。此序列与静态 call 等长（20B），模拟器已支持全部指令。
- **C89 边界（spec §4-5）**：做 = 位运算/复合赋值/++--/?:/逗号/sizeof/break/continue/do-while/switch（比较链）/goto/struct/union/enum/typedef/位域/数组（多维/不完整/退化）/初始化列表/static/extern/const/volatile/register/inline（接受即忽略）/void*/函数指针/cast/原型 + K&R 旧式定义/字符字面量/转义/字符串拼接/预处理全套。**不做** = long long、__asm__（内核中 SYMPLUS-PORT 改写）、VLA、复合字面量、宽字符、trigraph。
- **错误处理风格（M1 延续）**：词法/语法/预处理/链接错误 → stderr 消息 + `exit(1)`（工具型编译器，从简）。
- **M1 兼容**：`symcc -o out.asm` 游戏粘贴流程不变（全链路 = 编译 + 链接 → 绝对 asm）；`tests/run_tests.exe` 9 个 M1 测试在 Task 6 末尾必须全部通过。
- **提交**：每次任务结束一个 commit，commit message **绝不包含** `Co-Authored-By: Claude`。
- **Windows 构建**：Git Bash 下所有 gcc/make 调用前加 `PATH="/d/Downloads/msys64/mingw64/bin:$PATH"`（DLL 冲突，见 LEARNINGS.md）；原生 Windows 程序路径用 `C:/...` 完整路径；1MB 默认栈 → 大 buffer 用 static。
- **测试先行**：每个功能步骤先写失败测试（断言精确到退出码与屏幕内容），再实现，再验证。

**计划任务总览与依赖**：T1 预处理器 → (T2 类型系统, T3 运算符/语句) → T4 ABI 扩展 → T5 对象格式+codegen 改造 → T6 symld 链接器（T6 末尾恢复 run_tests 全链路）→ T7 gcc 式驱动 → T8 内核源码编译演练 → T9 收尾。

```c
/* tests/preproc_test.c — 预处理器单测（对象宏/函数宏/条件/include/-D/续行） */
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include "symcc/src/symcc.h"

static int npass = 0, nfail = 0;
#define CHECK(cond) do { if (cond) { npass++; } else { nfail++; printf("FAIL %s:%d: %s\n", __FILE__, __LINE__, #cond); } } while (0)

static char *pp(const char *src) {
    return preprocess_text(src, NULL, 0, NULL, 0);
}

static void test_object_macro(void) {
    char *out = pp("#define FOO 42\nint x = FOO;\n");
    CHECK(strstr(out, "x = 42"));
    CHECK(!strstr(out, "FOO"));
    free(out);
}
static void test_func_macro(void) {
    char *out = pp("#define ADD(a, b) ((a) + (b))\nint x = ADD(1, 2);\n");
    CHECK(strstr(out, "((1) + (2))"));
    free(out);
}
static void test_nested_macro(void) {
    char *out = pp("#define A 1\n#define B A\nint x = B;\n");
    CHECK(strstr(out, "x = 1"));
    free(out);
}
static void test_cond_ifdef(void) {
    char *out = pp("#define Y\n#ifdef Y\nint a;\n#else\nint b;\n#endif\n");
    CHECK(strstr(out, "int a"));
    CHECK(!strstr(out, "int b"));
    free(out);
}
static void test_if_expr(void) {
    char *out = pp("#define N 3\n#if N > 2\nint ok;\n#else\nint bad;\n#endif\n");
    CHECK(strstr(out, "int ok"));
    CHECK(!strstr(out, "int bad"));
    free(out);
}
static void test_if_undefined_is_zero(void) {
    char *out = pp("#if UNDEFINED_IDENT\nint bad;\n#else\nint ok;\n#endif\n");
    CHECK(strstr(out, "int ok"));
    free(out);
}
static void test_defined_op(void) {
    char *out = pp("#if defined(FOO)\nint bad;\n#elif !defined(FOO) && defined(BAR)\nint ok;\n#endif\n");
    CHECK(strstr(out, "int ok"));
    free(out);
}
static void test_stringize(void) {
    char *out = pp("#define STR(x) #x\nchar *s = STR(hello);\n");
    CHECK(strstr(out, "\"hello\""));
    free(out);
}
static void test_paste(void) {
    char *out = pp("#define CAT(a, b) a##b\nint CAT(foo, bar);\n");
    CHECK(strstr(out, "foobar"));
    free(out);
}
static void test_line_continuation(void) {
    char *out = pp("#define LONG(x) \\\n    ((x) + 1)\nint y = LONG(5);\n");
    CHECK(strstr(out, "((5) + 1)"));
    free(out);
}
static void test_undef(void) {
    char *out = pp("#define X 1\n#undef X\n#if defined(X)\nint bad;\n#else\nint ok;\n#endif\n");
    CHECK(strstr(out, "int ok"));
    free(out);
}
static void test_cmdline_defines(void) {
    const char *defs[] = { "VERSION=7", "DEBUG" };
    char *out = preprocess_text("int v = VERSION;\n#ifdef DEBUG\nint dbg;\n#endif\n", NULL, 0, defs, 2);
    CHECK(strstr(out, "v = 7"));
    CHECK(strstr(out, "int dbg"));
    free(out);
}
static void test_comments_removed(void) {
    char *out = pp("int x; /* gone */ int y; // gone2\n");
    CHECK(strstr(out, "int x"));
    CHECK(strstr(out, "int y"));
    CHECK(!strstr(out, "gone"));
    free(out);
}

    test_cond_ifdef();      test_if_expr();         test_if_undefined_is_zero();
    test_defined_op();      test_stringize();       test_paste();

    test_comments_removed();

    return nfail ? 1 : 0;
}
```

- [ ] **Step 4: 预处理器核心（preprocess.c 骨架 + 指令分派）**

结构：

```c
/* preprocess.c — M2 预处理器（token 流级） */
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include "symcc.h"

typedef struct Macro {
    struct Macro *next;
    char *name; int len;
    char **params; int nparams;    /* 函数宏参数名；对象宏 nparams=-1 */
    Token *body;                   /* 宏体 token 链表（不含 #/## 原样保留） */
    int expanding;                 /* 防自展开 */
} Macro;

static Macro *macros;              /* 全局宏表 */
static int pp_depth;               /* 嵌套 #include 深度限制（<64） */
```

`preprocess_tokens(Token *tok, ...)` 主循环：
- 遍历 token；`tok_at_bol(t) && t 是 '#'` → 指令处理（读下一 token 为指令名）：
  - `include`：后面是 `<...>`（找 `>`）或 `"..."`（找 `"`）。`"..."` 相对当前文件目录 + inc_dirs；`<...>` 只 inc_dirs。打开文件 → `tokenize` → 递归 `preprocess_tokens`（把结果接到输出流，pp_depth 限制 64 防循环，超限 exit(1)）。找不到文件 → `fprintf(stderr, "cannot open include %s\n")` exit(1)。**注意**：tokenize 需要文件全文 → 先 read_file（从 main.c 复制该小函数到 preprocess.c，或 main.c 导出——复制，保持模块独立）。
  - `define`：解析 `NAME` 或 `NAME(...)`（参数名列表，可空参 `F()`）→ 收集 body token 直到行尾（用 at_bol 判定行尾：下一个 at_bol 的 token 即行尾）。对象宏 nparams=-1。同名重定义直接覆盖（不检查）。
  - `undef`：删宏。
  - `ifdef`/`ifndef`：查宏表 → 压条件栈（skip 状态）。
  - `if`：展开行内 token（不进入输出）→ 常量表达式求值 → 压栈。
  - `elif`/`else`：翻转当前层 skip。
  - `endif`：弹栈。
  - 未知指令：`fprintf(stderr, "unknown preprocessor directive\n")` exit(1)。
- 非指令行 token：宏展开（Step 5）后加入输出流。

条件栈（int 数组 + 深度计数即可：`static int cond_skip[64]; static int cond_depth;`，值为 0/1 表示本层是否跳过。`elif` 翻转，`else` 置 0（本层此前为假才输出）——实现细节：栈元素存"本层是否已经通过（已取真分支）"。

- [ ] **Step 5: 宏展开（token 级替换 + # + ##）**

```c
/* 展开 token 流 head..tail（不含行尾）：返回新流（malloc）。 */
static Token *expand(Token *head, Token *tail) { ... }
```

规则（写死）：
- 对每个 token：IDENT 且查得宏 → 若 `expanding` 已置位 → 原样输出（防自展开）；否则替换：对象宏 → 复制 body token（递归展开 body，参数替换同时进行）；函数宏 → 收集实参 token 序列（按括号匹配切分，逗号分隔，允许空实参，行尾/EOF 未闭合 → exit(1)），逐一替换到 body 副本。
- 替换算法（chibicc 式）：先把 body 复制成"替换模板"，再对模板内每个 token：若是参数名 → 用实参的**展开结果**替换（实参先整体展开）；若是 `#` 后跟参数名 → 字符串化（token 文本 → `"..."` 字符串 token，转义 `"` 与 `\`）；若是 `A ## B` → 拼接（两 token 文本合并后重新 tokenize 成 token 序列）。
- 模板展开完后，对结果**整体再展开一遍**（让新引入的宏名展开），`expanding` 标记在替换期间置位。
- 字符串化（`#`）：参数展开结果**不**再展开（直接文本化）。
- 拼接：若拼出标识符 → 查宏再展开；数字拼接按文本合并。
- 实参收集需注意嵌套括号与字符串字面量内的逗号/括号（跳过 `"` 内的内容——用 token 的 kind==TK_STR 天然规避：逗号/括号是标点 token，字符串是 TK_STR 整体 ✓）。
- 行内宏展开的边界：函数宏实参收集到"行尾或 EOF"报错。

行尾判断：`tail` = 该指令行/普通行的最后一个 token（下一个 at_bol token 的前一个）。循环展开时以"本行全部 token"为输入。

`preprocess_text`：`tokenize(src)` → `preprocess_tokens` → 文本重建：token 依次输出，`TK_NUM`（`%lld` + u 后缀）、`TK_IDENT`/`TK_KEYWORD`（原文）、`TK_PUNCT`（原文 + 相邻 token 间加空格防粘连——简单起见**所有 token 间加空格**，多余空格不影响编译器）、`TK_STR`（`"` + 字节 + `"`）。返回 malloc 文本。

  ```c
      int bit_offset, bit_width;  /* 位域：位偏移（单元内，大端高位起）与宽度；非位域 = -1 */
      Member *next;
  };
  struct Type {
      enum TypeKind kind;
      Type *base;         /* PTR/ARRAY: 指向/元素类型；FUNC: 返回类型 */
      bool is_unsigned;
      int64_t array_len;  /* ARRAY: 元素数；-1 = 不完整 */
      Member *members;    /* STRUCT/UNION/ENUM */
      int size;           /* 布局字节数（STRUCT/UNION 4 对齐；ARRAY 元素总字节） */
      char *tag;          /* struct/union/enum 标签（malloc，可空） */
      bool is_static, is_extern, is_inline;  /* 声明级（GLOBAL 与 FUNC 层使用） */
      struct Type *ret_ty;   /* FUNC: 返回类型（= base 亦可，二选一实现时定） */
  };
  /* Node 新增 kind：ND_MEMBER, ND_CAST */
  /* Node 新增字段：int64_t member_off 不另加——ND_MEMBER 用 val 存字节偏移 */
  /* Global 改造：删 int64_t init_val；加 unsigned char *init_data; int init_data_len;
   * （标量初值也统一为 4 字节大端字节串；数组/struct 为完整字节布局） */
  ```
  位域类型统一为 `unsigned int` 语义（spec §11：位域按 unsigned int 存取，宽度 1-32）。
  布局规则（写死）：STRUCT 成员按声明顺序，offset 从 0 起**4 字节对齐**累加（每个成员先对齐到 4，再 +size）；位域不增加 offset，只在当前 4 字节单元内分配位（从单元最高位 bit0 起）；宽度 0 的位域 → 跳到下一单元边界；位域不能跨单元（放不下则推进到下一单元）；STRUCT 总大小 = 4 对齐。UNION 所有成员 offset=0，size = 最大成员大小 4 对齐。ENUM 成员 offset = 常量值（-1 表示无 tag 的匿名——tag 可空）。

```asm
    mov r1, 0
    screen r1, 0               ; setting[0] = 0 → ASCII 8 模式
    mov r1, 1

    lsl r9, r9, 16
    or r9, r9, @lo:__bss_start
    mov r10, @hi:__bss_end
    lsl r10, r10, 16
    or r10, r10, @lo:__bss_end
L_bss_loop:
    cmp r9, r10
    jae L_bss_done
    store_32 [r9], zr
    add r9, r9, 4
    jmp L_bss_loop
L_bss_done:
    call main
; 末尾 halt: jmp halt 由链接器统一输出
```

- [ ] **Step 3: link.c 实现（布局 → 符号 → 重定位 → 输出）**

```c
/* link.c — symld 链接器核心 */
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include "symcc/src/obj.h"
#include "emu/asm.h"
#include "config.h"   /* FRAMEBUF_BASE 字符串值 */

/* 段内标签 */
typedef struct LocalSym {
    struct LocalSym *next;
    char *name; int len;
    int obj; int segment;   /* 所属对象与段 */
    long off;               /* 段内偏移 */
} LocalSym;
/* 全局符号（.sym 行 + crt0 内置） */
typedef struct GSymbol {
    struct GSymbol *next;
    char *name; int len;
    bool is_data; int segment;
    long off;               /* 布局后绝对地址 */
    bool defined;           /* 布局完成 */
    bool builtin;           /* __bss_start/__bss_end */
} GSymbol;
```

实现流程（写死）：
1. 读 crt0 文件（fopen crt0_path，失败 → err）→ 逐行：`FRAMEBUF_BASE` 替换为 `0x2000` → 存为 obj[0] 的 text 行（crt0 无 data/bss/sym）。**内置符号注入**：布局后填 `__bss_start`/`__bss_end`（GSymbol builtin，地址计算见 4）。
2. **布局**：text_base=0；逐对象逐行（obj_line_size）累加 text 总长；data 紧随（4 对齐——行本身 4 对齐？数据行 U32 天然 4 对齐；字符串行 1-3 字节 → **对象边界 4 对齐**：data 基址 = 4 对齐（text 末尾向上取整）；bss 基址 = data 末尾 4 对齐。
3. **建表**：解析每个对象行（text/data）：`obj_label_name_len > 0` → LocalSym 记录（对象、段、当前偏移）；`.sym` 行 → GSymbol（`__bss_start` 等特殊名保留给内置）。**重复检查**：全局符号重名（排除 static 段内）→ err "duplicate symbol"。
4. **符号地址**：GSymbol 布局后填绝对地址：text 符号 = text_base + 段内偏移（从标签行位置算——**符号行 offset 由标签行决定**：.sym 行的 offset 字段忽略，按同名 LocalSym 的偏移 ✓）；data 同；bss 符号 = bss_base + 累计（bss 按声明顺序累加）；内置：`__bss_start` = data_end（4 对齐）、`__bss_end` = data_end + bss_total。
5. **重定位输出**：逐对象逐行重建（Step 规则）→ out_asm。行重建实现：
   ```c
   /* 把行拆成词（空格分隔），重建：操作数按引用形态替换 */
   static void emit_line(const char *line, ...);
   ```
   词级处理：`@name`/`@hi:name`/`@lo:name`（操作数位置）→ 数字；`call/jmp/条件跳转` 的操作数 → 符号/标签；`name:` 标签行 → 原样（函数 label 保留 / L 标签保留——**等等**：L 标签输出为数字吗？段内标签在输出 asm 中保留名字也行（游戏汇编器支持 label）——**决策：输出中 L 标签保留原名**（jmp L12 引用也保留——前提：**不会重名**（每函数独立编号？多对象 L12 重名！）。**写死**：L 标签与 s 标签（字符串）在**链接器内重命名**：`L12` → `L2_12`（对象号前缀）或数字解析。**更简单**：段内 L/s 标签全部解析为**数字**（绝对地址，无需改名）——jmp L12 → `jmp 0x12c8` ✓（游戏汇编器 jmp 接受数字 ✓）；函数标签保留名（全局唯一 ✓）。s%d 字符串标签引用是数据形态（@s0 → 数字）✓ 从不输出标签名。**最终决策**：输出中唯一保留的标签 = 全局函数名；L 标签引用一律数字。
   ——等等，函数名做标签输出时，函数定义行 `f:` 保留 ✓；引用 `call f` 保留 ✓；`jmp f`（函数地址跳转？罕见）保留 ✓。static 函数：段内标签 → 引用解析为数字 ✓ 但定义行 `f:` 会输出名字——**static 函数标签行也转数字**？static 函数在输出 asm 中保留 `f:` 名无妨（无重名风险？static 函数名可能跨对象重名！两个对象各有 static int helper() → 两处 `helper:` 重名 → 游戏汇编器冲突！**写死**：static 函数定义行也解析为数字形式——不行，函数体要 label…… 换个思路：**static 函数引用（call helper）解析为数字**（绝对地址），**定义行 `helper:` 保留名字但唯一化**？——定义行换成数字不行（没有"无标签"指令位置概念，跳转目标是地址，定义行本身不产生指令……）。
   **正确做法**：static 函数的定义行 `helper:` → 链接器**丢弃**（不输出）——因为所有引用已解析为数字（绝对地址），不需要标签 ✓！非 static 函数定义行保留（call main 引用 label ✓）。**写死**：链接器输出时，标签行按"全局函数符号（.sym T）"保留，其余标签行（L/s/static 函数）丢弃；引用按规则解析。检查：J16 引用 static 函数 → 段内表 → 数字 ✓。
6. **范围校验**：text+data 总长 ≤0x10000（J16）→ 超限 err "program exceeds 64KB (J16 limit)"; 所有 D16 解析值 ≤0xFFFF 校验 ✓。
7. **halt**：输出末尾 `halt:` + `jmp halt`。
8. out_bin：`asm_assemble(输出文本, buf, cap, &err)` → 写文件（失败 → err）。
9. 返回 true；错误统一写 err->msg（含符号名）。

```
  -save-temps       保留中间文件（.i/.s/.sym 于当前目录）
  --d32             数据引用 32 位装载（链接输出不变，编译期开关）
  -v                打印各阶段文件名到 stderr
无选项 = 全链路（每个文件 preprocess → compile obj → 统一 symld_link → 绝对 asm）
```
