# M2 编译器完整化（C89）设计文档

**日期**：2026-08-20
**前置**：M1 完成（symcc 单遍编译器 + 模拟器 + 游戏内 Hello 验收通过）
**目标**：symcc 从 M1 子集扩展为**完整 C89 子集**，配套 gcc 式驱动 CLI 与
**链接器**，最终能编译链接移植改写后的 Linux 0.11 内核全部 .c 文件，
产出可加载镜像（运行验证归 M3）。

## 1. 背景

M1 编译器支持约 20 个 C 特性的子集（9 关键字、无数组/结构体/预处理/位运算）。
Linux 0.11 内核源码（`Reference/Linux-0.11-main/`，51 个 .c、32 个 .h）大量使用
struct、数组、`#define` 宏、位运算、复合赋值、`++`/`--`、`?:`、`sizeof`、类型转换、
可变参数（printk/vsprintf）——M1 子集无法编译。

**用户决策**（2026-08-20 brainstorming）：
- 目标形态：**完整 C89**（非实用裁剪；C 标准无 C98，取 C89/C90——1990 年 ANSI C，
  Linux 0.11 时代编译器所用标准；天然排除 64 位 long long）
- 验收标准：**编译 + 链接**——C89 测试套件全绿 + 内核全部 .c 编译链接无错，
  产出可加载镜像（链接器纳入 M2；启动链/驱动归 M3）
- 工具链架构：**gcc 式驱动**——`-o` 直接输出最终产物，阶段开关可选保留中间产物

## 2. 范围总表

### 2.1 做（C89 完整）

**类型系统**：union、enum、struct 完善（tag 命名空间、嵌套、数组 of struct、`->`/`.`、
`sizeof(struct)`、结构体 `=` 整块拷贝）、struct 按值传参/返回、位域 bitfield、
typedef、存储类（static 内部链接+函数内静态、extern、const/volatile/register 接受并忽略）、
void* 隐式转换、函数指针、类型转换 (cast)、多维数组、数组初始化列表
（含 `char s[] = "..."`、部分初始化零填充）。

**运算符**：位运算 `& | ^ ~ << >>`、复合赋值全套（`+= -= *= /= %= &= |= ^= <<= >>=`）、
`++`/`--` 前后缀、`?:`、`sizeof`、逗号表达式。

**语句**：break、continue、do-while、switch（比较链实现，不做跳转表）、goto+标签。

**声明**：函数原型（标准 C89 语义 + 未声明调用按隐式 int）、K&R 旧式函数定义、
多声明器 `int a, b;`、声明中初始化、静态局部变量、字符串转义
（`\n \t \0 \x41 \101`）+ 相邻字符串拼接。

**预处理**（新模块，gcc 语义）：`#include`（`"..."`/`<...>`，`-I` 路径）、
`#define` 对象宏+函数宏、`#undef`、`#if/#elif/#else/#endif`（`defined()` +
整数常量表达式）、`#ifdef/#ifndef`、`#`/`##`（字符串化/连接）、命令行 `-D` 宏。

**ABI 扩展**：
- struct 按值传参：全栈拷贝（按 4 字节对齐连续拷贝）
- struct 返回：隐藏指针参数（调用方分配临时区，地址作首参传入）
- 可变参数：编译器内建 `__builtin_va_start(AP, LASTARG)`（生成
  `AP = r10 + 8 + 4*nargs`，指向第一个可变参数；全栈传参下可变参数在栈上
  连续排列）；`va_arg` 保持 0.11 `stdarg.h` 的纯宏指针运算
  （M2 有类型转换/sizeof 后天然可行）；`stdarg.h` 改写 1 行
  （`va_start` 宏 → 内建名）

### 2.2 不做（改写内核源码，0.11 不用）

- 64 位 long long（C89 无此类型）
- gcc 内联汇编 `__asm__`/`__volatile__`（改写点集中在 `include/asm/*.h`
  4 个文件 21 处 + 少数 .c ~10 处；M2 用 stub，M3 换真实实现）
- 变长数组、复合字面量、C99+ 特性、宽字符、三字母词

## 3. 工具链架构（gcc 式驱动）

```text
gcc 惯例                                symcc 对应
gcc -E foo.c                →           symcc -E foo.c         预处理产物（纯 C 文本）
gcc -S foo.c                →           symcc -S foo.c         单文件可重定位汇编文本
gcc -c foo.c                →           symcc -c foo.c         .sym 对象文件
gcc a.c b.c -o out          →           symcc a.c b.c -o out.asm  全链路最终产物
gcc -I inc -D__KERNEL__     →           symcc -I inc -D__KERNEL__ 同语义
```

**内部流水线**（单二进制 symcc，阶段开关决定停在哪一步）：

```
preprocess → tokenize → parse → codegen → assemble → link
   (新)        (现)      (现)     (扩展)    (复用)    (新)
```

- 默认（无阶段开关）：全链路，`-o out.asm` 输出**绝对地址的最终汇编文本**
  （多文件合并 + 重定位 + 数据段布局）——用户直接粘贴游戏
- 阶段开关 `-E`/`-S`/`-c` 停在对应阶段并落盘；`-save-temps` 保留全部中间产物
- `symld.exe` 独立暴露链接器（教学与独立测试）
- **M1 兼容**：`symcc x.c runtime/y.c -o out.asm` 现有用法不变

## 4. C89 语言特性详情

### 4.1 类型系统

- 基础类型：int/char/unsigned（M1 已有）；void（函数返回/空参数）
- **typedef**：类型别名，AST 层映射；可与存储类/限定符组合
- **enum**：常量表；成员值可显式指定、可自增；enum 常量可用于 case 标签、
  全局初始化值、数组大小
- **union**：布局 = 最大成员（对齐 4）；成员访问 = 偏移访问（与 struct 同机制）
- **struct**：tag 命名空间（`struct foo` 与 typedef 名互不冲突）；嵌套定义
  （成员可为匿名 struct？——C89 无匿名成员，不做）；自引用（指针）；
  `->` 与 `.` 访问；`sizeof(struct)`；结构体 `=`（整块 memcpy，按大小拷贝）
- **位域**：int/unsigned int 字段；**实现定义拍板：大端分配，声明顺序从
  存储单元最高位开始**；读写用掩码+移位；位域类型只支持 int/unsigned int
- **存储类**：`static`（文件级 = 内部链接，不导出对象符号表；函数内 = 静态
  存储，数据段分配，初始化一次）；`extern`（声明不定义）；`const`/`volatile`/
  `register` 接受并忽略（编译器无优化，语义天然成立）
- **void\***：与任意对象指针隐式互转（C89 语义；`NULL`/malloc 模式必需）
- **函数指针**：声明 `int (*fp)(int)`、调用 `fp(x)`、传参、sizeof
- **类型转换**：(int)(char)(unsigned)(指针) 全组合；char→int 符号/零扩展
  （M1 已有基座）；指针→整型、整型→指针直接搬移
- **数组**：多维（行主序）；不完整类型（extern `int arr[];` 声明）；数组
  形参退化为指针；`sizeof(arr)`（限同作用域完整数组）
- **初始化列表**：`{ ... }` 嵌套；`char s[] = "..."`（含末尾 NUL 与显式
  长度 `char s[10] = "ab"`）；部分初始化零填充；全局与局部均可（局部 = 栈
  上拷贝代码，全局 = 数据段直接填充）

### 4.2 运算符与语句

- 位运算映射（汇编层已有指令）：`&`→and、`|`→or、`^`→xor、`~`→nor 变体
  （not）、`<<`→lsl、`>>`→lsr（无符号）/asr（有符号）
- 复合赋值：`lhs op= rhs` 展开为 `lhs = lhs op rhs`（左值只求值一次——
  生成：求地址暂存 r9 → 求值 rhs → 装载旧值 → 运算 → 存回）
- `++`/`--`：前后缀；左值只求值一次；语义 = `lhs = lhs ± 1`（指针 ± 元素大小）
- `?:`：`cond ? a : b` = 分支合并（跳转结构，两侧分别求值）
- `sizeof`：类型或表达式（不求值）；char=1，int/指针=4，struct/union=布局大小
- 逗号表达式：左→右求值，结果 = 右侧
- break/continue：绑定最近循环；continue 跳循环尾（for 的增量表达式前）
- do-while：先体后判
- switch：case 常量表达式（enum/宏展开后）、default、fall-through、嵌套
  switch（每个 switch 独立 label 空间）；实现 = 顺序比较链（不做跳转表）
- goto+标签：C 标签 + 无条件跳转（编译器简单；跨函数 goto 不做——C89 也不许）

### 4.3 声明与函数

- 函数原型：`int f(int a, char *b);` 参数表解析；调用点按原型检查参数个数
  （不匹配报错；0.11 头文件全原型）
- 未声明函数调用：隐式 `int f()`（C89 兼容）
- K&R 旧式定义：`f(a, b) int a; char *b; { ... }`（参数名 + 类型声明行 +
  旧式调用 `f(1, "x")` 无原型检查）
- 多声明器 `int a, b = 3, *p;`（M1 限制解除）
- 静态局部变量：数据段分配 + 初始化一次（全局初始化表达式同规则）

### 4.4 预处理（新模块）

- 处理顺序：读文件 → 行级预处理（指令行 + 宏替换）→ 输出纯 C 文本
- `#include "x.h"`：先当前目录后 `-I` 路径；`#include <x.h>`：只搜 `-I`
  路径；include 深度限制（防环，如 64）
- 宏替换：对象宏与函数宏；参数替换 + 嵌套展开（宏内宏）；**展开递归禁止**
  （同宏出现于自身展开中则保留原名，标准语义）；`#` 字符串化、`##` 连接
- `#if` 表达式：整数常量表达式（支持全部 M2 整数运算符 + `defined(X)`）；
  未定义标识符在 #if 中视为 0（标准语义）
- `-D name[=value]` 命令行预定义宏
- 与 tokenize 的衔接：预处理产物是纯 C 文本（可 -E 落盘展示），tokenize 不变

## 5. ABI 扩展

### 5.1 struct 按值传参

- 实参：求值后按 4 字节块压栈——块地址从低到高依次 push（首块最后压入、
  落在最高地址），与单字实参的 `[r10+8+4k]` 布局连续一致（k=0 为首参数）
- 形参：被调方栈槽 = 完整结构体区域（按 4 字节块拷贝，帧大小含结构体槽）
- 无大小限制——一律栈拷贝（M2 不做寄存器优化）

### 5.2 struct 返回值

- 隐藏指针：调用方在栈上预留返回区，地址作**首参**传入（调用方
  `sub sp, sp, size` 预留 → push 返回区地址 → 其余实参 → call → 清理）；
  被调方将返回结构体拷入该区域，返回普通寄存器 r1 无所谓（调用方从
  返回区取）

### 5.3 可变参数

- `__builtin_va_start(AP, LASTARG)`：codegen 内建——生成
  `AP = r10 + 8 + 4*nargs`（跳过序言 push 与 nargs 个具名实参），
  AP 是 char* 局部变量
- `va_arg` 宏（0.11 stdarg.h）：`(AP += rounded(TYPE), *(TYPE *)(AP - rounded))`
  纯指针运算 ✓ 无需内建
- `va_end`：空宏
- `stdarg.h` 改写点：`#define va_start(AP, LASTARG) __builtin_va_start(AP, LASTARG)`
  （gcc 2.x 时代同款做法）；`__sparc__` 分支随 `#ifndef __sparc__` 自然排除
- 0.11 使用点：kernel/vsprintf.c（10 处）、printk.c（3 处）等——编译通过
  且 M3 运行时 printk 直接工作

## 6. 对象格式 .sym 与链接器

### 6.1 .sym 对象（symcc -c 输出，二进制自定义格式）

```
magic "SYMP" + 版本
.text 段（代码字节）
.data 段（已初始化：全局 + 字符串 + 数组/struct 初始化）
.bss  段（仅大小）
符号表：{name, 类型(函数/数据), 段, 段内偏移, 大小}
重定位表：{段内位置, 段, 目标符号, 类型}
```

重定位类型（2 种）：
| 类型 | 用途 | 语义 |
|---|---|---|
| R_ABS16 | 数据引用（mov imm / load/store [imm]）与跨对象跳转/调用 | 符号最终地址（≤0xFFFF；内核 <64KB 满足） |
| R_ABS32_LO / R_ABS32_HI | 数据地址 32 位装载（地址 >64KB：mov hi; lsl 16; or lo 两处） | hi/lo 分别重定位 |

段内跳转（L 标签）不产生重定位（单对象内 = 段内偏移，链接时加基址）。

### 6.2 codegen 输出形态（教学价值点）

- `symcc -S x.c`：可重定位汇编文本——数据引用保留 label 形态（`mov r1, s0`），
  未链接、符号引用可见
- `symcc -c x.c`：.sym 对象
- **symld 链接后才解析为绝对数字**——M1 的布局 pass 职责上移给链接器
  （游戏粘贴的是链接后产物，仍全数字兼容，M1 游戏验收结论不变）

### 6.3 链接器行为（symld）

1. 布局：crt0（内置文本，含 `call main` 重定位）→ 各对象 .text（命令行顺序）
   → .data → .bss
2. bss 清零：游戏 RAM 上电内容未验证（M0 遗留）——链接器生成清零循环代码
   （crt0 内：bss 大小已知时内联循环）
3. 符号规则：全局符号跨对象唯一（重复定义报错）、未定义报错（列出清单）；
   static 符号不导出
4. 输出：函数名保留为 label（游戏 jmp/call 支持 label）；全局变量/字符串
   解析为数字（游戏数据位置只认数字——M1 已验证原则）；L 标签解析为数字
5. 边界：跳转目标 ≤0xFFFF（内核 <64KB 满足）；数据地址任意（32 位装载）

## 11. 明确拍板的实现定义项（防歧义）

- 位域：大端，声明顺序从存储单元最高位起分配
- struct 传参：纯栈拷贝（4 字节对齐块），无寄存器优化
- struct 返回：隐藏指针首参
- switch：顺序比较链（无跳转表、无位测试优化）
